# 🚀 SaaS Help Center & Bug Reporting Portal

A comprehensive help center solution for SaaS applications featuring interactive FAQ, bug reporting system, and multi-channel support options.

## ✨ Features

### 🏠 Home Page
- Responsive hero section with search functionality
- Quick action cards for easy navigation
- Popular help articles section
- Dark/Light mode toggle
- Real-time search with debounce

### 🐛 Bug Report Form
- Multi-step form with progress indicator
- Auto-detection of browser/environment info
- File upload with drag & drop support
- Form validation (real-time)
- Save draft functionality (localStorage)
- Priority level selection
- Success message with reference ID

### ❓ FAQ Page
- Accordion-style FAQ items
- Category filtering system
- Search within FAQs
- Organized by categories

### 📞 Contact Page
- Multiple contact options (Live Chat, Email, Video Call, Phone)
- Contact form with attachments
- Support hours and global info

### 🛍️ Shopify Demo
- Custom product page template
- Liquid template integration
- Dynamic cart functionality

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Flexbox, Grid, Animations, CSS Variables
- **JavaScript (ES6+)** - DOM manipulation, Event handling
- **jQuery 3.6.0** - AJAX, Animations
- **Browser Developer Tools** - Debugging, Performance analysis
- **Shopify Liquid** - Template customization

## 🚀 Installation

1. Clone or download the project
2. Open `index.html` in your browser
3. Or use Live Server in VS Code

## 💻 Usage

1. **Dark Mode**: Click moon/sun icon
2. **Search**: Type in search bar
3. **Bug Report**: Fill form and submit
4. **FAQ**: Click questions to expand
5. **Contact**: Choose contact method
